RadarGridParameter¶

RadarGridParameters is the lowest level data structure used to represent a Range-Azimuth Grid in ISCE.

Factory¶

from isce3.product import radarGridParameters

obj = radarGridParameters(**kwds)

Documentation¶

class isce3.product.RadarGridParameters¶
add_margin(self: isce3.ext.isce3.product.RadarGridParameters, ymargin: int, xmargin: int, side: str = 'both') → isce3.ext.isce3.product.RadarGridParameters¶

Add margins to the RadarGridParameters object

Parameters:

  • ymargin (int) – The number of samples along the azimuth. Must be >0.

  • xmargin (int) – The number of samples along the slant range. Must be >0.

  • side (str) – The side where the margin will be added, and options are ‘start’, ‘stop’, and ‘both’. Defaults to ‘both’.

Returns:

The radar grid with the margins added.
