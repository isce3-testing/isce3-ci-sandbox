ISCE3 has the following dependencies

  1. C++ compiler - GCC 7.5 or above
  2. Python 3.7 or above
  3. Eigen 3.3.7 or above
  4. Numpy 1.20 or above
  5. GDAL 3.0 or above with Python bindings
  6. HDF5 1.10.2 or above with h5py
  7. CMake 3.18 or above
  8. CUDA 9.0 or above (for GPU-based processing)
  9. ruamel.yaml

Optional dependencies for unit testing and documentation generation are

  1. pytest (for Python unit tests)
  2. sphinx (for documenting Python code)
  3. doxygen (for documenting C++ code)

Note that some of our prerequisites are more recent than those provided by stable releases of common Linux distributions such as CentOS and Ubuntu. As such, we typically prefer to install these dependencies using the conda package manager, as it happens to provide suitable versions of all the packages we need.

A simple strategy for directory layouts which will be used here is as follows:

Assumed directory structure for installation
PathDescription
${ISCEHOME}/conda Miniconda3 installation directory
${ISCEHOME}/isce3 git checkout location
${ISCEHOME}/isce3/build CMake build directory
${ISCEHOME}/isce3/build/install CMake install prefix

Note that ${ISCEHOME} in these can be any directory on your machine. You can even use your home folder as the base for your directory structure.

Installing packages using builtin package manager

If you have access to a system with an Nvidia GPU which does not have the CUDA Toolkit installed, consider asking your system administrator to install it so that you can benefit from ISCE3's enhanced GPU processing capabilities.

If you would like to install the CUDA Toolkit on your own system, check for available CUDA packages from your Linux distribution's package manager or refer to the CUDA Installation Guide.

Installing Conda and Python packages

In this set of instructions, we rely on the conda package manager for installing Python dependencies. Downloads and installation instructions can be found here.

  1. First, create a list of all the required packages in a text file called "requirements.txt" located under ${ISCEHOME}/python.
    The contents of the requirements.txt file is shown below:

    fftw>=3
    gdal>=3.0
    h5py
    hdf5>=1.10.2
    numpy
    python>=3.6
    ruamel.yaml
    matplotlib
    scipy
    eigen
    git
    ninja
    pytest
    shapely
    libgcc-ng
    libstdcxx-ng
    yamale
    backoff
    cmake>=3.18
    gxx_linux-64

  2. We can then install these requirements as shown below:

    > conda update --all
    conda create -n ISCE3 -y
    conda activate ISCE3
    conda install -c conda-forge --file ${ISCEHOME}/python/requirements.txt

Install ISCE3 from source

In this section we will walk through the directory setup and build system instructions for building and installing ISCE3 with CMake.

Step 1: Get latest version of ISCE3 source

  1. Ensure that you are in the source folder
    > cd ${ISCEHOME}/
  2. Check out the latest version of the source code from git
    > git clone https://github-fn.jpl.nasa.gov/isce-3/isce isce3

Step 2: Build the software

  1. For our CMake build, we follow the practice of building outside of the source parent directory.
    To that end, we first create a temporary build directory:

    > cd ${ISCEHOME}/isce3
    > mkdir build
    > cd build

    Note: if you wish to build the CUDA extensions and CMake does not find your CUDA compiler, you can specify its location via

    export CUDACXX=/usr/local/cuda/bin/nvcc

  2. Run CMake configuration with the correct inputs and compiler flags

    > cmake .. \
    -DCMAKE_CUDA_HOST_COMPILER=$CXX \
    -DCMAKE_PREFIX_PATH=$CONDA_PREFIX \
    -DCMAKE_INSTALL_PREFIX=install

    We leave it to the user to determine which GCC to assign to -DCMAKE_CUDA_HOST_COMPILER. Please refer to the System Requirements section of the Installation Guide Linux in your version of CUDA's Online Documentation.

    Other optional arguments can be added to the CMake line

    Additional cmake options
    Option Description
    -DWITH_CUDA=OFFDo not attempt to detect CUDA support (default "Auto" will auto-detect CUDA toolchain, but can be explicitly required/ignored with ON/OFF)
    -DPython_EXECUTABLE=<path_to_python_exe>Specify this if CMake detects the wrong python installation
    -DCMAKE_BUILD_TYPE=DebugBuild with minimal optimization and full debugging info. Default is RelWithDebInfo - a balanced combination of debugging and optimization.

    The following env variables can also be used as hints for CMake's auto-detection. Use these settings if cmake fails to identify the right compilers or install locations of dependencies. Note that if you previously ran CMake and want to change these values, the old values have been cached, so you need to delete CMakeCache.txt from the build dir so they are recomputed.

    Additional environment variables impacting cmake
    VariableDescription
    CC Path to the C compiler
    CXX Path to the C++ compiler
    GDAL_ROOT Path to location of gdal installation. With anaconda, $CONDA_PREFIX

  3. Build the software

    > make VERBOSE=ON

  4. Install the software to your specified CMAKE_INSTALL_PREFIX

    > make install

  5. Run the unit tests to ensure that software was built and installed correctly

    Note that our python packages must be installed before they can be tested.

    > ctest

Step 3: Install and set environment variables

If you're developing ISCE3 as a regular user and installing to a non-system CMAKE_INSTALL_PREFIX, you will need to define the following environment variables to be able to use the libraries and python packages.

  1. Setup the environment variables.

    Environment variables to set after installing ISCE3
    VariableSettingDescription
    PATH$PATH:${ISCEHOME}/isce3/build/install/binFor executables installed by ISCE3
    PYTHONPATH$PYTHONPATH:${ISCEHOME}/isce3/build/install/packagesISCE3 python package
